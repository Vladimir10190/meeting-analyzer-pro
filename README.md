# AI-анализатор видеовстреч PRO

Локальное учебное приложение для обработки записей MP4 и WebM с компьютера, Яндекс.Диска, Google Диска и Dropbox. Оно отправляет видео провайдеру для распознавания речи и составляет конспект по полученной расшифровке. История хранится в `data/meetings/`. Для каждой встречи сохраняются имя файла, источник, дата добавления, статус, расшифровка и конспект.

## Запуск в Windows PowerShell

1. Установите Node.js 22 или новее.
2. Откройте PowerShell в папке проекта и выполните:

   ```powershell
   node --version
   npm ci
   Copy-Item .env.example .env.local
   notepad .env.local
   ```

3. Заполните `OPENAI_API_KEY` ключом провайдера. Для OpenAI-совместимого провайдера укажите базовый адрес API в `OPENAI_BASE_URL`, например `https://example.com/v1`. Укажите доступные у провайдера модели в `STT_MODEL` и `SUMMARY_MODEL`. По умолчанию видео отправляется в `/audio/transcriptions`. Для передачи видео через `/chat/completions` с `input_audio` задайте `TRANSCRIPTION_MODE=chat_audio`. Провайдер должен принимать видеоконтейнеры MP4 и WebM. Создание конспекта использует `/chat/completions` со структурированным JSON-ответом по схеме. Для VseLLM используйте `https://api.vsellm.ru/v1`, режим `chat_audio` и модель `google/gemini-3.1-flash-lite`. Если `OPENAI_BASE_URL` не задан, используется `https://api.openai.com/v1`. Переменные процесса имеют приоритет над файлом. После изменения настроек перезапустите сервер.
4. Запустите сервер и откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

   ```powershell
   node server.mjs
   ```

Для остановки нажмите Ctrl+C. Запускайте один экземпляр сервера из этой папки. Без ключа можно открыть страницу и просматривать ранее сохранённые встречи.

## Использование и проверки

Выберите видео с разборчивой русской речью. Нажмите **Выбрать файл** для ручной загрузки или добавьте запись из облака.

1. Загрузите MP4 или WebM на Яндекс.Диск, Google Диск или в Dropbox. Скопируйте ссылку на конкретный файл и разрешите скачивание без входа в аккаунт. Для Google Диска включите доступ **Всем, у кого есть ссылка**.
2. В разделе **Анализ встреч** вставьте её в поле **Ссылка на видеозапись** и нажмите **Добавить из облака**. Подходят публичные ссылки, которые сервисы выдают при выборе **Поделиться**. Для облачного импорта OAuth-токены не требуются.
3. Вы увидите этапы **Получение файла**, **Распознавание речи**, **AI-анализ** и **Готово**. В карточке встречи доступны краткое содержание, решения, задачи, открытые вопросы и расшифровка.

Если облако требует вход, дополнительное подтверждение или файл по ссылке недоступен, скачайте запись в своём аккаунте и воспользуйтесь кнопкой **Выбрать файл**. Импорт начинается после нажатия **Добавить из облака**.

При повторном импорте сервер скачивает файл и сравнивает его SHA-256 с контрольными суммами в истории. Если содержимое совпадает, появится кнопка **Открыть готовый результат**. Заменённый в облаке файл с другой контрольной суммой анализируется заново.

Приложение обрабатывает одну запись за раз. Лимит файла составляет 250 МиБ и пять минут. Провайдер может устанавливать меньшие ограничения на размер запроса. Приложение проверяет формат, длительность и наличие звуковой дорожки. Распознавание речи и обработку тишины выполняет провайдер. Качество результата зависит от записи и модели.

Приложение временно сохраняет исходное видео рядом с историей и передаёт его целиком выбранному провайдеру. После обработки временный файл удаляется. Расшифровка также передаётся провайдеру для составления конспекта. Доступ к API требует сети и может тарифицироваться отдельно.

Запустите проверки командой `npm test`. Они подставляют тестовые ответы облачных сервисов и AI-провайдера. Для ручной приёмки добавьте MP4 по облачной ссылке, обновите страницу после обработки и повторно добавьте ту же ссылку. Откройте сохранённый результат, затем проверьте недоступную ссылку и ручную загрузку WebM. Закрытие вкладки не прерывает задачу. Если сервер перезапустится во время обработки, задача получит статус **Ошибка** и запись можно будет добавить повторно.

## Повторное использование

`analysis.mjs` экспортирует `processVideo(videoPath)`. Функция принимает путь к локальному видео и возвращает промис с `{ transcript, summary }`. Её можно вызывать из серверного кода без HTTP и без истории. Удаление переданного файла остаётся за вызывающим кодом. При прямом вызове задайте конфигурацию через переменные процесса или запустите скрипт командой `node --env-file=.env.local script.mjs`.

Документация OpenAI по [распознаванию речи](https://developers.openai.com/api/docs/guides/speech-to-text) и [структурированному выводу](https://developers.openai.com/api/docs/guides/structured-outputs).

## Развёртывание в ChatGPT Sites

Версия для Sites собирается командой `npm run build:sites`. Worker раздаёт интерфейс и API. История и этапы записываются в D1, временные файлы — в R2. Миграции находятся в `drizzle/`. Для публикации нужны привязки `DB` и `BUCKET` из `.openai/hosting.json`, секрет `VSELLM_API_KEY` и настройка `MEETING_OWNER_ID` со стабильным идентификатором владельца на этом сайте. Дополнительные настройки провайдера можно задать переменными `OPENAI_BASE_URL`, `TRANSCRIPTION_MODE`, `STT_MODEL` и `SUMMARY_MODEL`.

Любой посетитель сайта может без входа загрузить MP4 или WebM с компьютера или добавить запись по облачной ссылке. Обработка запускается автоматически. Все посетители видят общую историю, этапы обработки и готовые конспекты с решениями, задачами и открытыми вопросами. Для полных расшифровок предусмотрен вход владельца. В общий список добавляйте учебные записи, конспекты которых можно показывать другим посетителям.

На сайте действует лимит 10 МиБ и 5 минут на запись. Держите вкладку открытой во время обработки. Если её закрыть, обработку можно продолжить с сохранённого этапа при следующем открытии сайта. Если предыдущий запрос оборвался внутри этапа, сайт дождётся освобождения блокировки и повторит этап. Локальная история из `data/meetings/` и история сайта хранятся отдельно.

Запустите `npm run test:sites`, чтобы собрать и проверить Worker с тестовой базой SQLite и тестовыми ответами AI-провайдера. В настройках доступа ChatGPT Sites выберите «Все, у кого есть ссылка», чтобы форма добавления и общая история открывались без входа.
